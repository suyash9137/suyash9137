# Install your GitHub profile README

1. Open https://github.com/new.
2. Create a **public** repository named exactly `suyash9137` (the repository name must match your GitHub username).
3. Add a README, or use the existing profile repository if you already have one.
4. Upload `README.md` to the repository root.
5. Upload the entire `assets` folder so the banner is at `assets/banner.png`.
6. Commit the changes. Your profile README should appear on https://github.com/suyash9137.

## Before publishing

- Check the project descriptions and links in `README.md`; edit anything that has changed.
- The COAST-TRACE repository link uses `coastaltrace`, matching the repository name shown on your profile. GitHub URLs are case-insensitive.
- The Smart Student Career Agent is described as a project concept; add a repository link once you have a public repo for it.
- The GitHub stats and activity graph are provided by third-party public image services. If one is unavailable, remove that image line or replace the service.
- The skill icons are loaded from skillicons.dev, so they require an internet connection when the README is viewed.

## Updating the banner

Replace `assets/banner.png` with another image using the same filename, then commit the change. The README itself does not need editing.
